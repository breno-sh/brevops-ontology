Oráculo offline da fatia NET

PILOT-NET-ORACLE. Avaliador de decisão de acesso para security group AWS, firewall GCP, NSG Azure, security list e NSG OCI; juiz de tradução para as 12 direções; gabarito de decomposição. Escrito sem ler mapeamento, glossário nem saída de pipeline. Só biblioteca padrão.

Uso

import sys; sys.path.insert(0, "$BO_REPO/pilot/net/oracle")
import net_oracle as no
no.evaluate_fixture(fx)                          # {"decisions": {flow_id: {value, code, splits}}, "validity": {...}}
no.judge(src_fx, alvo, perdas, "aws->google")    # veredito ACCEPT | ACCEPT_WITH_DECLARED_LOSS | UNDETERMINED | REJECT
no.compare_decomposition(esperado, produzido)    # unidades faltando, sobrando, tipo errado (camada Terraform ignorada)

CLI: python -I -m bo.pilot_net_oracle.judge --source FX.json --target ALVO.json --losses PERDAS.json.

Formato

Configuração = recursos Terraform como JSON: {"resources": [{"type", "name", "values"}]}. Referência é "ref:TIPO.NOME"; valor simbólico (variável, saída computada, referência não resolvida) é "sym:rótulo". targets liga o alvo abstrato (vm1) à instância. Fluxo: {flow_id, target, direction, protocol, port, remote, state: new} ou {flow_id, target, state: return, of, reply_port}; a porta de origem do fluxo novo é 49152 (parte do fluxo sintético, não default de provedor). read.not_read marca o que não foi lido ({"of": endereço, "what": "rules" | "attachment" | "state_tracking"}). HCL precisa ser convertido para esse JSON por quem o produz; o oráculo não executa nada.

Semântica

semantics_profile.json: cada parâmetro com valor, nível e evidência do SERVICE-EVIDENCE. O que não tem evidência na leitura é ponto de escolha: o avaliador decide sob todos os valores e só responde se todos concordam; senão UNKNOWN com o código do ponto que dividiu (INCOMPLETE_READ, UNKNOWN_SYMBOLIC_INPUT, MISSING_EVIDENCE). Leituras: strict (published, derived), default (+ oracle_derived, usada no gabarito) e lenient (+ interpreted).

Juiz

Negado na origem e permitido no alvo reprova sempre (perda declarada não cobre). Divergência só passa coberta por perda do catálogo da direção (directions.json) que cubra aquele tipo; senão é perda silenciosa. Origem UNKNOWN e alvo permitido é UNDETERMINED (só LOSS-NET-UNKNOWN-INPUT cobre). Alvo inválido reprova. O juiz julga pelos fluxos da fixture: o que nenhum fluxo amostra não é visto.
